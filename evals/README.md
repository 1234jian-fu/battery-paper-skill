# 可重复合同检查

所有数据均为 **SYNTHETIC**，不代表真实论文、实验、阅读或作者授权。
`example.invalid` 仅是结构字段占位符；检查不联网、不下载、不调用模型、不安装依赖。

`run_contract_checks.py` 通过真实命令行子进程调用 `scripts/paper_workbench.py`，
不导入被测实现，也不复用单元测试工厂。每个场景在系统临时目录新建独立项目，
结束后清理。所有写入局限于该临时目录；仓库内的 fixture 只读。
每个只读命令前后比较文件字节的 SHA-256 和目录集合。

## 运行

在 skill 根目录运行单场景（Python 3.10+，仅标准库）：

```text
python -B -X utf8 evals/run_contract_checks.py --case count --json
```

可用场景：`initialization`、`threshold`、`dates`、`identities`、`policies`、
`delivery`、`count`、`readonly`。单场景脚本返回观测值；它不是自评分器。
若已安装 `skill-evaluator`，执行其确定性 runner，由 `evals.json` 的固定预期评分：

```text
python -B -X utf8 PATH_TO_SKILL_EVALUATOR/scripts/run_script_checks.py --skill PATH_TO_BATTERY_PAPER_SKILL --json
```

当前定义 **8 个检查、115 个断言**，每个确定性场景都有 `script_checks`。
将运行结果保存到 skill 目录之外，避免把某次机器运行状态当成长期正确性保证。

## 预期值的独立推导

| 场景 | 可手工核对的预期 |
|---|---|
| 初始化 | 新建项目的证据、来源均为 0；第二次初始化不应改变任何已有文件；删去的唯一 `issues.md` 应被补回 |
| 共享基底 | 59 个唯一合格身份差 1；补入第 60 个后差 0；所有来源只标记 F1，所以要求中的 F2 仍缺失 |
| 滚动日期 | 截止 2026-10-30 回推五年为 2021-10-30，边界包含；9 条中仅第 1、2、6 条完全在窗口内，因此为 3，缺口 60−3=57 |
| 日期精度 | 2021 全年跨下界，2026-10 整月跨截止日；2020 首次在线早于窗口，即使卷期为 2025 也不计；无效首次在线不回退到卷期 |
| 闰日 | 2024-02-29 回推五年落在非闰年 2019，因此使用 2019-02-28 |
| 别名与无效项 | 30 个共享论文身份各有 2 条记录，共 60 条；15 对还共享规范化 DOI，15 对是 DOI/无 DOI 别名，均只算 30 篇；5 条混合质量记录中只有第 1 条合格 |
| 自定政策 | 60 条合格记录对默认 60 缺口为 0；明确记录的最低 80 政策缺口为 80−60=20；未授权政策只提示，不改文件 |
| 交付 | `" Alpha. "` 是 8 个字符，`"Beta.\n"` 是 6 个，总计 14；中文 `"合成观察。"` 是 5 个；删除段首空格后为 13，首差异下标为 0 |
| 正文计数 | 去空白：`电池` 2 + `alpha-beta` 10 + `12.` 3 + `Li+` 3 + `好。` 2 = **20**；汉字 3；英文词 `alpha-beta`、`Li` 共 2；空行分隔 2 段 |
| 图注计数 | `图` 1 + `1.` 2 + `Test.` 5 = **8**；汉字 1，英文词 1，段落 1 |
| 无副作用 | status/check/corpus/sources/count/delivery-check 共 6 个命令；必须全部返回 0，且完整临时项目及输入文件字节、目录集合不变 |

## 范围与缺口

- 此层验证记录和 CLI 合同，不验证来源真实、作者确实阅读、科学结论、相关性或改写保义。
- JSON 内部逐字一致不证明实际 Markdown/Word/浏览器交付一致；没有自动解析实际正文。
- 不涵盖全部恶意输入、操作系统权限、符号链接、并发写入和所有日期/字符组合；更细的输入边界由 `tests/` 补充。
- `trigger-queries.json` 有 20 条标签查询：10 条应触发，10 条共享电池或论文关键词的近似负例。它是待运行数据集，不能据此宣称触发准确率。
- 尚未执行模型触发重复运行、with-skill/without-skill 写作质量对照或真实文献任务，因此不报告它们的通过率或增益。
