# 真实论文局部写作质量对照

本轮补齐了句子—段落—文章三级审查和表征对标规则。下面是实际运行结果，不以规则数量或脚本通过代替写作质量。

## 真实参照与输入

- Zhang 等，*Electrolyte design for reversible zinc metal chemistry*，Nature Communications 16, 71 (2025)，[出版社原文](https://www.nature.com/articles/s41467-024-55657-1)。核读相关主文、方法、Fig. 3图注和实图，提取水环境、Raman、X射线与MD事实。
- Pan 等，*A solid-state lithium-ion battery with micron-sized silicon anode operating free from external pressure*，Nature Communications 15, 2263 (2024)，[出版社原文](https://www.nature.com/articles/s41467-024-46472-9)。核读压力、电极及性能相关主文、方法、Fig. 4–5图注和实图。

本目录的事实包是对已发表事实的独立整理，英文输出是写作练习，不是新实验或作者原文。出版社全文、图像和SI未放入本仓库。下载文献与附件已在空间充足的本地资料库另存，下载不等于科学核读。

## 实际方法与变更

两篇论文，各比较无技能、原始技能和优化技能，共6份有效正文；每组每案仅一次。使用相同模型与推理档位、相同事实和任务，全部为新会话。上游基准提交为 `239299de2d28e6ce1dc2687f9de36e3dbfa93851`。

首次文件读取方式的6次运行均被环境策略阻止，只返回阻塞说明，全部排除，没有当作低分样本。随后改为直接附文本：无技能组仅附事实；另外两组附对应SKILL和全部references文本，不附docs、evals、测试或其他组答案。保持只读环境和原审批策略，不放宽权限。运行设置及输入哈希在[results.json](results.json)。

禁用全局技能、插件和记忆，离线检查系统技能目录消失；成功运行的真实轨迹未见工具调用或工具错误。本轮验证的是显式注入技能文本时的写作输出，不是自动触发率、按需读文件能力或严格容器隔离效果。

两位独立模型评审先根据随机标签正文、统一事实和[预先确定的量表](rubric.md)独立判断，再用来源组织笔记核对；每案标签单独打乱。两份实际笔记保留在[judge-notes](judge-notes/)，没有提供给写作组；可选数据未被采用不自动扣分。逐维理由和具体问题保留在[评审记录](reviews/)，主代理另读了全部6份正文。它不是外部人类专家评审。

## 如何解释结果

本轮三组都保留了关键事实与证据边界，未发现由优化版引入的重大事实错误。锌案例的组织差异主要是：原版较早引出可逆性问题；优化版将X射线与Raman合段，另用一段解释MD；无技能组也能清楚说明聚集比例的非单调变化。固态案例都区分了内建压力与外加压力、20圈后的取样成像、模型应力和不同构型的循环结果。

分数及两位评审的分歧应连同正文阅读。少量措辞或取材差异不能支持“整体质量显著提升”的结论；缺省可选数字也不是事实错误。保留原稿中有效结构和清楚句子，比为显示优化而机械重写更合适。

本轮能够确认流程补齐、例句可核查及当前有限场景下的事实边界保护；不能据此证明完整稿件或未见论文上的稳定优势。两个案例也参与了规则开发，且事实包已明确不少风险，因此存在开发案例偏差和评分上限效应。没有重复采样、统计显著性分析、60篇新稿语料建设或整篇实际稿件的端到端验证。

句级来源映射、每段写后对照与实质修改、篇级反向提纲与真实论文结构对照已写入技能，完整稿件效果仍需在作者的具体稿件上检查。正文任务本次要求不展示审核表，因此不能从最终正文反推每个内部审查动作都已执行。

## 评审反馈后的单次针对性复测

锌优化稿中的物种重新分布概括被评审二认为过于笼统，评审一未扣分。依据这一可定位问题，表征指南只补入一条通用规则：定量结果后的概括须说明已支持的具体方向、非单调趋势、差异或权衡，不能仅重复宽泛结论。

另冻存修订后的技能，仅重跑锌优化组一次；事实、任务、模型及推理档位与原组一致，附件中仅表征指南变化。[新正文](outputs/zinc-optimized-post-review.md)明确写出HDE相对DE具有更少的溶剂分离离子对、更多CIP和更少AGG。主代理核对其数字和比较方向与事实包一致；执行轨迹未见工具调用或工具错误。详情见[复测记录](feedback-followup.json)。

这是收到开发反馈后的定向检查，没有重新盲评或打分；单次随机生成不能把文字变化归因于这条规则，也不能证明稳定增益。上表六份原始正文与评分全部保留，未用复测替换。仓库最终规则包含这条反馈修订，原始对照使用修订前快照。
