# 电池论文的通用写法与证据边界

本库供中文草稿审核及英文写作组织使用。所有中英文示意均为**自拟模板，不是文献原句、译文或已核事实**；方括号必须由当前项目的真实数据、状态和方法替换。没有数据时只能交付待填结构，不能写成已观察结果。

本文件提供通用判别规则；真实论文入口与实际核读范围集中见[语料索引](literature-corpus.md)。本文件的自拟模板不计为文献来源，也不携带旧项目的样品、图号或结论。正式文稿中的文献事实、机制归属和引用须逐项核对原文。

## 1. 共用写作动作

通常按“对象与状态 → 观察 → 同条件比较 → 有限解释 → 必要衔接”组织；这是可选动作，不能机械地每段重复五步。每段回答一个主要问题，可由多个互补测试共同回答。

- **观察：** 先说测到了什么。自拟结构：在[状态]下，[测试]显示[可见特征/测量量]。英文：`At [state], [measurement] shows [observation].`
- **比较：** 写清基准、工况和指标。自拟结构：与[对照]相比，[指定量]由[值]变为[值]。英文：`Compared with [control], [quantity] changes from [value] to [value] under [conditions].`
- **有限解释：** 直接读数可以“显示”；多项间接证据用“支持”或“与……一致”。提出机制时注明未排除的解释，不靠换动词修复缺失证据。英文：`Together with [independent evidence], this result supports [bounded interpretation].`
- **衔接：** 前一结果留下实际问题时，再引出下一项测试。自拟结构：[已知事实]尚不能区分[解释]，因此采用[测试]考察[问题]。英文：`To distinguish [alternatives], [measurement] was used to examine [question].`

删去重复目的句、形容词和无信息总结；保留测量对象、样品状态、可比条件及归一化基准。结构借鉴、文献事实和本研究观察应在工作记录中分开标识。

## 2. 写作前必须锁定的计量规则

| 项目 | 必须分清的量与写法 |
|---|---|
| 电池与电位 | 列明半/全/对称/三电极等构型、工作/对/参比电极；电位写明相对何种参比。全电池端电压不等于某一电极电位 |
| 状态 | 制备态、化成后、指定圈数/SOC/电位、静置后和循环后分别命名；取样、清洗、空气暴露和压力等按相关性记录 |
| 容量 | 比容量说明分母是活性物质、复合材料、单/双电极还是器件质量；面容量说明几何面积；体积容量说明体积范围。投料质量与实际活性量不得混用 |
| 电流与 C-rate | 区分 mA、mA g⁻¹、mA cm⁻²；每项明确归一基准。C-rate 说明 1 C 的容量基准及相应电流，不能默认不同材料的 1 C 可无条件横比 |
| 倍率方向 | 分别写充电倍率、放电倍率和恒压截止规则；仅变放电为放电倍率测试，仅变充电为充电倍率测试，两者同变写充放电同步变倍率。快充主张需充电工况、时间及 SOC/容量窗口支持 |
| 循环与效率 | 保持率 Qₙ/Qᵣ 明确参考圈 r。一般充放电容量效率明确 Q_dis/Q_chg；沉积/剥离效率按实际协议定义 Q_strip/Q_plate 等，不混用；能量效率另由能量计算 |
| 电导/电阻 | 离子电导率、电子电导率、总电导率、迁移数、阻抗及电子电阻分别命名；本征量与有效量、膜/压片/极片/整电池分别限定 |
| 阻抗与扩散 | EIS 拟合电阻依赖模型和状态，不等于独立实测离子电导率；CV/GITT/PITT 等推得的扩散参数按适用条件称表观或化学扩散系数，不等于电导或迁移数 |
| 比值与变化 | “A 为 B 的 k 倍”取 k=A/B；“相对增加”取 (A−B)/B，“相对减少”取 (B−A)/B。百分比与百分点不同，避免“提高 k 倍”歧义；误差和有效位数按原始精度 |
| 能量与功率 | 能量由对应电压–容量数据积分；功率定义时间区间。分别注明材料、电极、电极对或完整器件质量/体积，计入范围不同的结果不得直接排名 |
| 实用工况 | 对结论有影响的载量、厚度、电解液量、N/P 或容量匹配、温度、压力、截止规则应可追溯；缺失条件不能默认为相同 |

若从电阻换算电导率，只有电流路径、有效几何和选用电阻明确时才用 σ=L/(RA)；该换算与原电阻是同一证据链，不能当作两项独立验证。部分电导的测量需有对应选择性电极和边界条件。离子迁移数不是电导率；仅在适用的输运定义和模型下才讨论二者的组合。

## 3. 常用测试写法卡

以下每张卡的中文与英文均为自拟结构示意。选择与当前体系和证据相符的卡片，不要求每篇论文具备全部测试。

### 01 设计与组成筛选

- **动作：** 当前限制 → 设计变量 → 对照 → 已测指标间的取舍。区分投料、实测组成、收率和质量损失。
- **中文示意：** 随[组成变量]变化，[指标]呈[趋势]；[选定配方]在[已测约束]之间取得较合适的平衡，用于后续[范围]研究。
- **英文结构：** `Across [tested range], [composition] offers a balance between [measured properties] and was selected for [purpose].`
- **边界：** “最佳”只覆盖实际比较范围和明确目标；不能替未测配方补出润湿、形貌或循环排名，也不从模板预填配方。

### 02 SEM/TEM、截面与三维结构

- **动作：** 样品与状态 → 视野内特征 → 合理尺度下比较 → 独立证据确认身份。跨尺度时说明主体从界面、颗粒切换到极片。
- **中文示意：** 在[观察区域]，[样品]呈现[可辨特征]；与[对照]相比，[尺寸/裂纹/接触等]存在[差异]。
- **英文结构：** `Images of [sample at state] reveal [feature] within [observed region], compared with [control].`
- **边界：** 亮暗差不单独确认成分；局部“未见”不等于全体不存在。二维像不直接证明三维连续网络或体积变化率；统计结论需可追溯视野和计数。

### 03 EDS、元素面扫与线扫

- **动作：** 元素信号存在 → 指定区域分布 → 沿标定路径的相对位置 → 与形貌对应。
- **中文示意：** [元素]信号在[视野]内呈[分布]；沿[路径]的线扫在[位置]出现[特征]，与[形貌区域]相对应。
- **英文结构：** `The [element] signal is detected at [location] along [defined path], consistent with [spatial observation].`
- **边界：** 共定位不等于化学键、体相掺杂或连续包覆；强度受厚度和采集条件影响。未检出需限定检测能力，不自动判为零含量。

### 04 XRD、衍射精修与结构变化

- **动作：** 比较状态 → 可靠成套特征/拟合参数 → 变量趋势 → 可检测物相或结构解释。
- **中文示意：** [样品]中的[衍射特征]与[经核对的物相]相符；在[一致处理]后，[参数]发生[变化]。
- **英文结构：** `[Diffraction features] are consistent with [phase], while [parameter] changes upon [treatment].`
- **边界：** 单一重叠峰不能确认复杂物相；峰移需排查校准、应变等因素；没有特征峰不等于不存在。表面位置、全部组分和反应路径不能仅由常规 XRD 指定；定量相含量需方法支持。

### 05 Raman、FTIR、NMR 及溶剂化表征

- **动作：** 明确测试对象 → 峰/谱带变化 → 有依据的归属 → 互补表征或模型约束。
- **中文示意：** 随[条件]变化，[信号]呈[变化]。结合[核对后的归属及独立证据]，该结果支持[局部结构/相互作用]的变化。
- **英文结构：** `Changes in [spectral feature], together with [evidence], support a change in [bounded structural assignment].`
- **边界：** 峰高不直接等于组分含量；归属需排查重叠、背景和测试条件。单一峰移不足以唯一确定键合、配位数或完整溶剂化结构；计算快照也不等于实测物种分布。

交叉极化NMR等信号用于讨论物种比例时，还须考虑弛豫、转移效率及测试温度；结构辨别与定量群体统计分别写。真实案例见[B07](corpus/b07.md)。

### 06 XPS、深度分析与界面化学

- **动作：** 取样与表面处理 → 可分辨组分 → 一致规则下比较 → 限定于探测范围的演变。
- **中文示意：** 在[状态]，[芯能级]谱包含[有依据的组分]；按一致拟合规则，[相对比例/结合能]呈[变化]。
- **英文结构：** `Within the probed surface region, [component] exhibits [change] under consistent fitting criteria.`
- **边界：** 表面原子比例不等于体相质量分数；峰位需校准。溅射会改变样品，深度序列不直接等同未扰动真实层序；新增组分本身不证明其保护作用或唯一反应路径。

### 07 原位/工况与非原位状态序列

- **动作：** 测量模式与时间/电位 → 可追踪信号 → 与反应进程对应 → 说明时间及空间分辨率。
- **中文示意：** 在[实际监测条件]下，[信号]于[状态区间]发生[变化]；该变化与[同步记录]对应。
- **英文结构：** `During [monitored process], [signal] evolves over [state range] and correlates with [recorded response].`
- **边界：** 实际运行且同步观测才使用相应工况表述；非原位多点取样不能写成连续原位跟踪。相关性不单独证明因果，未覆盖状态不补写反应顺序。

### 08 接触角、吸液与浸润

- **动作：** 样品表面/膜/极片、液体和时刻 → 角度或质量变化 → 同条件比较 → 润湿或吸液解释。
- **中文示意：** 在[t]时，[样品]对[液体]的表观接触角为[值]；独立吸液测试显示[实测变化]。
- **英文结构：** `At [time], [sample] exhibits an apparent contact angle of [value] with [liquid].`
- **边界：** 表面铺展、吸液质量与全厚度浸润分别报告；近零角度不证明所有孔隙充满，也不直接给出离子电导率。多孔表面的吸收与粗糙度需考虑。

### 09 电子/离子电导与迁移数

- **动作：** 对象与状态 → 电极/几何/温度/压力 → 原始响应与计算方法 → 准确命名的量 → 比较。
- **中文示意：** 在[边界条件]下，由[明确方法]得到[样品]的[电子/离子/总/有效电导率]为[值]；相较[对照]，[准确指标]呈[趋势]。
- **英文结构：** `Using [method and boundary conditions], the [defined conductivity] of [sample] was determined to be [value].`
- **边界：** EIS 需识别对应电阻和载流路径，直流极化需说明阻挡/非阻挡条件及稳态假设；电子电阻下降不能改称离子电导提高。迁移数方法及界面修正需适用，不能将其直接称为离子传输速度。不同状态、几何或压力的数值避免无条件横比。

### 10 EIS 与等效电路

- **动作：** 构型、温度、SOC/电位、静置与循环状态 → 谱图特征 → 合理模型和参数 → 与独立证据关联。
- **中文示意：** 在[同一状态]，依据[模型]拟合得到[A/B]的[参数名]为[值/值]；结合[独立证据]，该差异支持[有限解释]。
- **英文结构：** `At [matched state], fitting with [model] yields [defined parameter], consistent with [independent evidence].`
- **边界：** 弧减小不同时证明电子和离子传输均提高；整电池响应含多个部件贡献。R_ct、膜电阻、接触电阻等归属需依据，不能只按元件编号指定；拟合优度不证明模型唯一正确。

### 11 CV、峰间距与扫描速率分析

- **动作：** 构型/窗口/扫描速率 → 指定峰或积分量 → 拟合方法与区间 → 限定的反应比较。
- **中文示意：** 在[速率范围]，[指定峰]的[峰位/电流]呈[变化]；按[关系式]拟合得到[参数]，支持[反应范围内的趋势]。
- **英文结构：** `For [specified peak] over [scan-rate range], fitting [relationship] gives [parameter], suggesting [bounded trend].`
- **边界：** 峰间距受极化和多种过程影响；b 值及 k₁v+k₂v 分解依赖模型，不能独立证明储存机制或将“电容性贡献”直接等同赝电容。峰电流–v¹ᐟ² 斜率不是扩散系数；仅在适用模型且其他因子相同时，扩散比才可能由斜率比的平方求得，须写出假设，不能把斜率倍数当作扩散倍数。

### 12 GITT/PITT、扩散参数与活化能

- **动作：** 脉冲/弛豫协议与状态 → 原始电压/电流响应 → 模型适用区间 → 表观或化学扩散参数及不确定性。
- **中文示意：** 根据[实际模型]及[满足的条件]，在[状态区间]估算的[准确扩散参数名]为[范围]。
- **英文结构：** `Within [state range], [defined diffusion coefficient] was estimated using [model and assumptions].`
- **边界：** 几何、活性面积、近平衡及扩散近似等须适用；相变、显著欧姆/界面极化会限制解释。该参数不等同直接测得的微观自扩散或电导率。温变拟合的表观活化能需注明所拟物理量和区间，不自动等同单条原子迁移路径势垒。

### 13 恒流充放电、循环与电压衰减

- **动作：** 构型/窗口/电流/归一基准 → 曲线形状或关键容量 → 指定参考圈保持率 → 对应状态诊断。
- **中文示意：** 在[条件]下，[样品]第[N]圈的[归一基准]容量为[值]，相对第[r]圈保持[值]；[平均电压/效率]另呈[实测趋势]。
- **英文结构：** `At [conditions], [sample] delivers [capacity and basis] after [N] cycles, retaining [fraction] relative to cycle [r].`
- **边界：** 活化增容与稳定后衰减分开；容量、平均电压、能量和库仑效率不是同一指标。单只电池按实际范围描述；不虚构重复、误差或统计显著性。循环曲线本身不能唯一确定持久机制。

### 14 倍率、快充与恢复测试

- **动作：** 1 C 定义与构型 → 分别说明充/放电程序 → 关键高倍率和恢复容量 → 准确命名结论。
- **中文示意：** 在[固定充电规则]下，放电倍率由[r₁]提高至[r₂]时，[容量变化]；恢复至[r₁]后为[值]。本测试评价[高倍率放电能力]。
- **英文结构：** `With charging fixed at [protocol], discharge at [rates] yields [capacity], followed by [recovery result].`
- **边界：** 若两向同时改变，明确写同步变倍率；固定放电而改变充电也单独命名。快充报告达到指定 SOC/容量的时间、恒流/恒压规则及窗口；高放电倍率、CV 扫描速率或传输参数不能替代快充测试。恢复容量不是长期可逆性证明。

### 15 金属沉积/剥离、效率与对称电池

- **动作：** 基底/电极储量 → 电流密度及单次面容量 → 沉积/剥离协议 → 效率、过电位或失效 → 形貌/化学诊断。
- **中文示意：** 在[j]和每次[面容量]条件下，[构型]呈现[效率/极化/运行时间]；该结果与[对应状态证据]相一致。
- **英文结构：** `At [current density] and [areal capacity per step], [configuration] exhibits [measured response].`
- **边界：** 对称电池稳定电压不直接给出库仑效率或排除软短路；需说明效率算法、截止和是否保留储量。成核过电位不单独证明无枝晶；Li、Na、Zn 的副反应、参比和测试协议分别核对。

沉积与剥离协议不对称时分别给出电流、容量和必要压力，不能把高沉积电流改写为同电流双向快循环；真实案例见[B09](corpus/b09.md)。

### 16 溶解、吸附、迁移与催化

- **动作：** 物种与浓度 → 接触/电化学条件 → 可观测变化 → 对照及质量/电荷信息 → 区分作用。
- **中文示意：** 经[条件]处理后，[溶液或电极信号]发生[变化]；结合[对照/定量证据]，该结果支持[吸附或反应的有限判断]。
- **英文结构：** `Following [treatment], [signal] changes, supporting [limited assignment] in conjunction with [control].`
- **边界：** 脱色不独立证明催化，需排除沉淀、分解等；吸附强不等于反应更快。抑制穿梭/自放电需相应电化学或迁移证据；非水转化体系结论不能直接移用于水系锌。

### 17 力学、隔膜、热与稳定性

- **动作：** 对象/状态/尺寸 → 加载、升温或扫描协议 → 直接指标 → 同条件比较 → 相关功能验证。
- **中文示意：** 在[测试协议]下，[样品]的[强度/剥离力/热收缩/热响应]为[值]；其与[电池表现]之间的联系由[独立证据]评估。
- **英文结构：** `Under [protocol], [sample] exhibits [measured property], with its relevance assessed by [independent test].`
- **边界：** 拉伸、黏附、模量和韧性分别命名；穿刺或热收缩不等于整电池安全认证。LSV/CV 起始电流受电极、扫描速率与反应动力学影响，不直接给出热力学稳定窗口或长期相容性。安全主张与实际试验范围一致。

### 18 全电池、软包与器件能量

- **动作：** 完整构型与容量匹配 → 载量/电解液/压力等工况 → 电压–容量与器件指标 → 计量范围内比较。
- **中文示意：** 在[构型及关键条件]下，按[明确质量/体积范围]计算的[能量/功率]为[值]；该结果对应[已测试器件层级]。
- **英文结构：** `For [cell configuration], [energy or power] calculated on a [defined mass/volume] basis reaches [value] under [conditions].`
- **边界：** 电极材料比容量不自动转成完整器件能量密度；应明确集流体、电解液、壳体等是否计入。扣式、软包与多层器件分别比较；负极过量、电解液过量和外加压力须按结论相关性披露。

### 19 DFT、分子模拟与局部机制

- **动作：** 实验约束/建模动机 → 代表结构与控制变量 → 能量、结构或动力学量 → 比较 → 模型范围。
- **中文示意：** 在[代表模型]中，沿[物种及路径]计算得到[准确能量/动力学指标]；结果支持该模型下的[局部趋势]。
- **英文结构：** `For [representative model], [computed quantity] along [defined process] supports [local interpretation].`
- **边界：** 吸附能、结合能、反应自由能和迁移势垒分开；能量正负与大小按所用定义解释。更强吸附不直接推出更快动力学；静态能量不等于反应速率。理想界面、有限采样和单一路径不足以唯一证明整电池机制。

### 20 连续模型、场分布与多尺度联系

- **动作：** 变量/尺度/方程 → 参数来源与边界 → 同工况同状态比较 → 定量指标 → 实验验证和敏感性。
- **中文示意：** 在[统一状态]，[场变量]在[区域]呈[分布]；依据[明确指标]，[不均匀性等量]相对[基准]变化[值]。
- **英文结构：** `At [matched state], [field variable] exhibits [distribution], quantified using [defined metric].`
- **边界：** 浓度、SOC、电势、电流、反应速率、应力和温度分别命名；色标、量纲与归一基准可比。二维/一维结果的三维展示不等于独立三维求解；未经参数传递和验证不声称跨尺度定量预测。

## 4. 标题、图注与段落审核

- 标题指向本节真实变量、过程或证据，例如自拟结构“[变量]对[对象/过程]的影响”；不能预置固定题名、每图一节或固定六图。
- 图注交代子图的对象、状态、测试、符号及误差含义；不把待证机制或整段讨论塞入图注。照片、示意图、实测曲线和模拟结果明确区分。
- 每个数字能回到当前原始记录；相对倍数有明确分子分母；误差条、重复次数和“显著”有实际依据。
- 每个解释能指出直接证据、辅助证据与剩余限制；不同测试是互补证据时，不改写成全部独立“证明”同一机制。
- 每段删去无法由当前材料支持的句子；对照不完全可比时说明限制。精简后仍保留构型、状态、倍率方向及质量/面积/器件归一基准。

本库覆盖常用电池测试的语言组织与高频证据边界，不替代具体体系的方法原文、仪器校准、数据处理协议或安全标准。未列方法须另查对应原始方法与适用条件；模板不能作为科学结论或参考文献使用。
