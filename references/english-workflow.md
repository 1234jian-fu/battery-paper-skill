# 英文原文映射与重构

中译英及英改英均适用；已有英文无需先重译整篇中文。中文释义供作者审核，不冒称源作者的中文原句。源稿命题、自己的图与数据共同限定科学内容。

| 步骤 | 动作 | 产物 |
|---|---|---|
| E1接续 | 版本、语言、段句ID、相邻段任务、锁定范围 | 本次修改接口 |
| E2保护 | 抽对象/状态/量/条件/方向/基准/数字/否定/因果/限定/图引用 | 命题与术语表 |
| E3配源 | 从近五年至少60篇共享库选同部分、同测试/任务子集 | 位置、中文义、适配理由 |
| E4提结构 | 主语、动作、条件、比较、结果、限定；主题链、时态语态与句长 | 有源结构卡 |
| E5中文组织 | 根据自己的命题决定主语、拆合、调序、比较方式 | 原文结构→本稿中文信息顺序 |
| E6英文起草 | 用自己的证据重构；真正难句可给少量局部候选 | 自然英文，不换名套句 |
| E7连贯 | 已知→新信息、主语链、指代、比较平行、条件修饰 | 定点调整，不机械长短交替 |
| E8规范 | 冠词、数、时态、并列、修饰、单位、缩写、化学式、价态 | 错误与建议分开 |
| E9保义 | 对原命题、图/证据、正式引用；拆合后回接 | 通过/待核/修正及范围 |
| E10作者审阅 | 保留好句，保存取舍与版本 | 候选或确认状态 |

完整近期表达校准须共享基底及当前任务覆盖均达标；普通翻译、局部纠错可先做但不称完成全链。只有实际统计才给语料句长、动词、连接词频次，并说明抽样范围；频率不等于期刊规定。

原文结构卡记录来源ID、位置、必要短摘、中文义、段内角色、句法动作和不可迁移事实。允许多对多，自己的观察、原创承接和普通语法不硬配母句。每个最终英文句保留句ID，并按实际依据关联中文命题、自己的证据及可适用的来源ID；原创承接、自己的观察/计算、作者提供或确认的方法、沿用确认稿均可没有外部来源，必须如实记录依据，不能硬配母句。表达来源不支持自己的实验结果。

## 保义重点

检查increase by/to，同数字样品对调、增减反转、否定遗漏、条件修饰对象、百分比/百分点、单位前缀/指数、价态、处理/循环/荷电状态、构型、离子/电子指标、相关/因果及图引用。

数字守恒只是报警，回译可能自动补足遗漏，均不能独立证明保义。原稿与证据冲突则记录原命题→冲突证据→拟修正，按授权处理，不能借语言润色静默改科学结论。

不硬设所有句子≤30词、固定段句数/被动比例或“顶刊连接词排名”。从当前电池方向与论文部分学习信息顺序和负荷，稳定术语不为变化而替换。However须真实转折，Therefore须推导关系，平行观察可不用连接词。

之后进入S11和末轮S12。学术humanizer只去冗余、宣传及机械表达，不删条件/限定。回填最后英文句表、证据、中文释义和词数；表中英文与最终正文逐字一致。
