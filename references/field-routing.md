# 电池论文的领域定位与检索路由

本文件用于选择当前稿件需要的研究方向、证据和检索入口。它不是必做实验清单，也不要求一篇论文覆盖所有电池体系、材料部件或机制。先确认作者材料和真实研究问题，再选一个主路由及必要的交叉路由；不得默认研究对象是导电剂、某种元素复合物或既有项目。

## 1. 建立当前项目的定位卡

仅填已知事实；缺失项记为“待确认”，不从参考论文补全。

| 维度 | 需要记录的内容 |
|---|---|
| 化学体系 | 电池类别、活性材料、实际参与反应或迁移的物种；例如 Li、Na、K、Zn，以及是否涉及 H⁺、共嵌入或多物种反应 |
| 介质与环境 | 非水/水系、液态/凝胶/固态、温度、气氛；按研究相关性记录 pH、压力等 |
| 研究部件 | 正极、负极、电解液、隔膜、界面、导电剂、粘结剂、集流体、复合电极、器件或模型；可多选但须确定主对象 |
| 电池构型 | 半电池、全电池、对称电池、三电极、无负极、软包、其他；工作/对/参比电极及电位基准 |
| 变量与对照 | 实际改变的组成、结构或工况；基准样品；其他条件是否可比；配方按本项目记录，不预置比例 |
| 目标问题 | 例如容量衰减、界面副反应、传输限制、沉积不均、结构失稳或制造约束；避免只写“提升性能” |
| 状态与尺度 | 制备态、化成后、指定 SOC/电位、充满/放空、循环后；分子、颗粒、极片、界面或器件 |
| 可用证据 | 已有原始数据/图像/方法、重复次数、误差、可支持的最强主张；计划实验与实测结果分别记录 |
| 比较基准 | 活性物质/复合物/电极/器件质量、几何面积或体积；载量、厚度、孔隙率、电解液量及电极容量匹配等必要条件 |
| 写作任务 | 当前章节、拟回答的问题、作者指定期刊或语言；标题、图数和结构由当前证据决定 |

“正极/负极”按电池中的角色命名；“阳极/阴极反应”随充放电过程变化，避免未经定义混用。SOC 的算法、参考容量和起点需按当前项目确认。

## 2. 按体系选择主路由

下列关键词是组合检索入口，不是机制结论。将体系词与具体材料、部件、测试状态及方法词组合；没有相应证据时不能把检索词写成研究发现。

| 体系路由 | 优先辨识的问题 | 可组合的英文检索词 | 关键边界 |
|---|---|---|---|
| 锂离子电池 | 正负极反应、容量匹配、传输和界面演变；嵌入、合金化与转化分别识别 | lithium-ion battery; intercalation; alloying; conversion; electrode degradation | 半电池结果不直接代表全电池；扣式电池倍率表现不能自动外推快充器件 |
| 锂金属/无负极电池 | 沉积/剥离、活性锂损失、界面、容量储备和工作压力 | lithium metal; anode-free; plating stripping; lithium inventory; Coulombic efficiency | 对称电池寿命与沉积/剥离效率是不同证据；富锂对电极可能掩盖锂损失 |
| 钠/钾离子及金属电池 | 储存路径、工作电位、溶剂化、界面和沉积；区分离子与金属构型 | sodium-ion; potassium-ion; hard carbon; sodium metal; potassium metal | 不沿用锂体系的扩散参数、界面组成、电位基准或储存机制 |
| 水系锌电池 | Zn 沉积/剥离、析氢/腐蚀、正极反应及电解液环境 | aqueous zinc battery; zinc deposition; hydrogen evolution; corrosion; proton co-insertion | 不能仅由容量或单一峰认定 Zn²⁺ 储存；需辨别 H⁺、副产物、溶解和沉积等贡献 |
| 硫/硒及其他转化电池 | 活性物种转化、可溶中间体、迁移、自放电和反应限制 | sulfur battery; selenium battery; conversion reaction; soluble intermediates; shuttle; self-discharge | 按 Li/Na/K 等实际体系检索；吸附、催化、抑制迁移和提高利用率分别验证 |
| 全固态/混合固液电池 | 固体电解质、接触、复合电极、相容性、压力与失效 | solid-state battery; solid electrolyte; composite electrode; contact loss; stack pressure | 明确是否含液体及其量；固态电解质本体电导不代表复合电极或整电池传输 |
| 其他水系/多价体系 | 实际载流物种、溶剂与质子参与、沉积或嵌入可逆性 | aqueous battery; magnesium battery; calcium battery; aluminum battery; charge carrier | 先建立该体系来源；不把化学计量价态直接当作已证明的可逆电荷补偿机制 |
| 液流/金属空气及其他器件 | 活性物质与介质、流动/气体供给、催化电极、器件损耗 | redox flow battery; metal-air battery; mass transport; gas diffusion electrode | 属扩展入口；需补充本领域方法和器件计量规则，不套用常规嵌入电池的全部指标 |

## 3. 按研究部件选择交叉路由

| 部件或任务 | 适合组织的证据问题 | 可组合的英文检索词 | 常见越界 |
|---|---|---|---|
| 正极 | 结构/价态变化、氧化还原、溶解、表面与体相失稳、容量与电压衰减 | cathode; phase transition; redox; surface reconstruction; voltage decay | 表面表征代替体相结论；平均电压下降与容量下降混写 |
| 负极 | 嵌入、合金化、转化或金属沉积的身份；体积、接触、界面与效率 | anode; insertion; alloying; conversion; volume change; interphase | 将嵌入称为沉积；将非原位形貌作为连续演变的直接记录 |
| 电解液 | 配方、溶剂化、离子输运、稳定性和界面形成之间的联系 | electrolyte formulation; solvation; ion transport; electrochemical stability; interphase | 单一光谱推出完整溶剂化结构；电导率与迁移数互相替代；扫描窗口等同长期稳定窗口 |
| 隔膜/功能膜 | 厚度、孔结构、润湿、选择性、力学/热收缩及电池表现 | separator; membrane; wettability; permeability; thermal shrinkage; selectivity | 接触角等同体内浸润或离子电导；热收缩试验等同整电池安全性 |
| 固体电解质 | 相组成、致密化、体相/晶界电阻、部分电导与电极相容性 | solid electrolyte; grain boundary; ionic conductivity; electronic leakage; compatibility | 未分离电阻就指定体相或晶界；总电导直接当作目标离子电导 |
| 电极界面/人工界面层 | 形成条件、局部化学、厚度/位置、传输和随循环的变化 | electrode interface; interphase; artificial interphase; depth profiling; operando | 检测到组分就断言保护作用；用 SEI、CEI 泛指未确认的任意涂层或接触界面 |
| 导电剂/粘结剂/集流体 | 本体与复合电极中功能、分布、接触、电子/离子通道、力学或工艺约束 | conductive additive; binder; current collector; dry electrode; percolation; adhesion | 把独立压片或膜的指标当作复合电极本征量；默认每个辅助组分都需承担双传输 |
| 电极工程/器件 | 载量、厚度、孔隙、容量匹配、电解液与压力、充电规则、能量和制造条件 | thick electrode; practical loading; full cell; pouch cell; lean electrolyte; energy density | 只给材料比容量就宣称器件高能量；仅凭软包照片判断实用性 |
| 原子/分子计算 | 代表模型、吸附、反应路径、迁移、溶剂化与实验约束 | DFT; adsorption energy; migration barrier; reaction free energy; molecular dynamics | 吸附更强直接等同催化更快；单一路径势垒直接等同整电池倍率 |
| 连续/多尺度计算 | 传输、反应、电势、应力、热与非均匀性；参数来源和验证 | porous electrode model; finite element; multiphysics; reaction distribution; sensitivity analysis | 场变量混名；归一化云图代替绝对量；未经耦合宣称跨尺度预测 |

## 4. 把路由转化为写作任务

1. 用一句话写明“在[构型与工况]下，[对象]的[具体问题]是否随[变量]改变”。问题应能由当前证据回答。
2. 为每项核心主张配一项直接证据，注明需要的互补证据和仍未排除的解释；缺失证据保留为限制或后续工作。
3. 选择同体系、同对象、可比工况的原始研究作为首要来源；跨体系论文可借方法或论证结构，其机制与数值需重新验证。综述适合发现来源，不能替代对关键原始证据的核对。
4. 检索记录标明标题、DOI/正式入口、日期、相关性、实际读取范围、图表/段落位置与拟支持主张。候选、已下载、已读摘要、已核原文分别计数。
5. 按当前技能的文献基底要求执行；本路由本身不代表已完成任何数量的检索或精读。若另有历史来源索引，仅将其作为候选入口，按题名或 DOI 核对，不依赖旧项目编号。
6. 按当前证据决定图组、段落和标题；不预置固定图数、统一题名、电极配方或必须出现的机制章节。新数据改变研究重点时更新定位卡。

本文件提供路由和审核边界，不提供任何项目结论、具体配方、已核文献计数或可直接引用的原文。
