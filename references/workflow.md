# 执行流程与返工

不预置固定材料、六图或机制。先恢复确认结构和好句、保留/调整/待核、理由与影响位置。当前作者指令优先于仍有效旧约定；候选不自动覆盖确认稿。作者命名选择和原始证据核验的事实分别记录。

| 步骤 | 输入与动作 | 输出/返工 |
|---|---|---|
| S01接续 | 稿、图、历史、取舍；确定范围与保护项 | 范围卡、继承清单、源版本；范围变更时更新 |
| S02读图 | 面板、连线、坐标、量、单位、状态与原始表比较 | 子图事实及冲突；缺图不编发现 |
| S03结构 | 接续有效结构，定图间职责/图内模块/段落任务 | 暂定论证链；不支持某一跳则调整 |
| S04句任务 | 主信息、M/T/L与辅助功能、前后关系 | 每句为何需要；不凑句或重复目的 |
| S05近期库 | 按任务检索核验，整稿至少60篇 | 真实核读进度与任务覆盖；缺口不冒称完成 |
| S06提炼 | 匹配正文、相邻图注/方法及上下文 | 原文位置、短摘、中文义、结构/数据句法 |
| S07映射 | 校准S03/S04；自己的对象/证据适配原文动作 | 候选和来源说明；事实移植或强配母句退回 |
| S08成段 | 比较顺序、主题链、观察解释、必要承接 | 段落及图注；单句有源不等于全段连贯 |
| S09科学 | 构型、状态、量、条件、基准、方向、机制 | 定点科学/逻辑修正；边界不足降低主张 |
| S10英文 | 按英文流程，已有英文可直入 | 英文、中文义、多对多映射；漂移回查 |
| S11审查 | 最终语言对命题、图、来源与正式引用 | 问题及实际检查范围；不虚构认证 |
| S12自然化 | 去冗余、宣传与机械衔接，保义验收并回填 | 报表→逻辑总结→正文；发现错误仍须修正 |

S03/S04先给检索可修正目标，S06后形成有源映射。来源问题回S05/S06，结构回S03/S07，科学回S09，英文保义回S10。修后只查受影响内容，不无限叠加“再润色”。

方法句可用T-方法，观察或性能句用T-结果，计算程序与计算结果再分子类；不把“制备了什么”写成“表征证明了什么”。背景、设计依据等按实际论述功能标注，三类用于审核而非强制套句。

## 按论文部分组织

- 标题/小标题：范围和内容匹配，标题之间体现论证推进；没有通用顶刊字数硬规则。
- 摘要：需求收窄到具体矛盾、设计、主要认识及有范围的意义。只选必要数据，不搬测试清单。
- 引言：需求→具体限制→已有路线及缺口→本文设计；概述与最新结果一致。
- 方法：真实关键复现条件，仿组织不借参数，不补编缺失实验。
- 结果与讨论：按科学任务/证据模块推进，观察→比较→有限解释可相邻；不逐测试重复问答。
- 结论：提炼全文认识，不增加新结果；构筑/性能/机制只是候选，不强制三点。
- 图注：面板、对象、状态、必要条件/符号逐项对应；主图和支撑分开，不重复整段机制。

## 最后自然化

S09查科学，S11查当前语言及引用，S12最后处理自然度并验收。删除空泛、重复、宣传、机械连接和不必要同义轮换；稳定术语可重复，清楚原句可保留。不加幽默、情绪、个性旁白、故意混乱，不保证任何检测器结果。不硬设每句词数、段句数、被动或名词化比例。

保护材料连接符、化学式、状态、方向、否定/限定、证据动词及正式引用。若末轮发现实质错误，回对应步骤纠正并重新验收；不能为坚持“最后一步”留错。只在实际执行后声称某工具或审稿流程通过。

每次结束保存源版本、当前阶段、确认稿、问题、下一步。作者接受前为候选；合稿获准后按确认内容和模板整合，检查渲染及图像质量。
