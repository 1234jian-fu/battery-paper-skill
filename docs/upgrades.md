### 规则如何改变

| 实际发现 | 本版写作决策 | 来源入口 |
|---|---|---|
| 相似名称的量可能来自不同尺度、探针或分母 | 核对量的定义后再联合解释，不将局域/瞬态参数直接替换为整体性能参数 | B23、B24、B31 |
| 多方法实验采用不同电流、负载或电池 | 保留各自工况和证据职责，避免写成同电池同步观测 | B24、B30 |
| 模型没有包含某机制，或仅复现定性形貌 | 缺项不能排除机制，相关与相似不自动构成因果或定量证明 | B21、B25 |
| 信号同时可能来自宿主和副相 | 用状态与互补对照处理归属竞争，不把峰消失直接等同物种消失或比例 | B26 |
| 实测双电极归一值与虚拟软包估算并存 | 数值的分母、实测/估算身份进入正文，并跨摘要和结论保持一致 | B29 |
| 机制发现被用来提出设计建议 | 宏观审查核对预测与验证之间的桥梁，没有验证时收窄设计结论 | B24、B30 |

详细边界集中在[表征指南](../references/characterization-writing.md)和阅读卡；[全文审查](../references/review-protocol.md)增加最强主张回查。技能入口只增加按任务检索的路径，没有将所有卡片塞进入口。
